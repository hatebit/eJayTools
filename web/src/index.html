EMP

eJay Mix Player

Play a mix on your sound card, or write any bar range to a 44.1 kHz WAV. The terminal UI browses a whole MIX folder, seeks and exports.

Render an arrangement to a PNG, one row per track, from a single song or from every song in every tree in one run.

About the project

An independent, open-source project that keeps the music you made with eJay usable on today’s computers.

eJay turned a home computer into a loop-based studio in the late 1990s: pick samples, drop them on a grid, arrange them into a track. Plenty of songs were saved as .MIX projects, and many of them have been unplayable for years.

eJay Tools opens those projects and the original sample banks directly. A song can be played back, written to a WAV file or drawn as a PNG arrangement, without installing the old software.

Everything runs locally, on the files you already have. No account, no upload, no online service in between.

Five formats, one toolset. Dance, Rave, HipHop, Dance 2 and Techno 2 projects are detected automatically from their file signature.

Four downloads and a browser page. A command-line player, a terminal player, a PNG renderer and a converter for single .PXD sample files, plus the browser page that decodes them without installing anything.

74 songs as a test set. Every project in the reference corpus is decoded and written back byte for byte, so the tools reproduce the original arrangement exactly.
